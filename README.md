# Guess-Game

A simple number guessing game built with HTML, CSS, and JavaScript.

## About
The computer picks a random number between 1 and 100, and the player tries to guess it.

After each guess, the game says whether the guess is too high, too low, or correct, and keeps track of the how many attempts the player has made.

## Features
 - Random number generation
 - Input validation
 - Feedback for each guess
 - Attempt counter
 - Repeated guesses intil the correct number is found


## Built With
  - HTML5
  - CSS3
  - JavaScript


## How to Play

 1. Start the game.
 2. Enter a nmber between 1 and 100.
 3. Submit your guess.
 4. Use the feedback to determine wheter to guess higher or lower.
 5. Continue until you find the correct number.
